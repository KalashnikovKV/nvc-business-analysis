# 01. Резюме, проблема, цели

## 1.1 Резюме

NVC Maps превращает короткую съёмку небольшого участка поверхности на телефоне с LiDAR в пакет игровой карты: визуальный меш, коллизия, отчёт о качестве. Сборщик проверяет карту в браузере (ходьба по коллизии + сравнение с кадром съёмки). Разработчик игры забирает GLB и сам выбирает масштаб персонажа.

## 1.2 Проблема

| Сейчас | Нужно |
|--------|--------|
| Есть видео реального места | Нужны упрощённый визуал и отдельная коллизия в метрах датчика |
| Карту собирают ручной фотограмметрией и правят в редакторе | Один воспроизводимый прогон без ручной доводки геометрии |
| Чтобы понять, «ходибельна» ли карта, ставят движок | Быстрая проверка в браузере до импорта |
| Нет единого контракта «визуал + коллизия + метрики / отказ» | Понятный пакет и явный fail с причиной |

**Боль:** нельзя быстро и повторяемо получить из короткой съёмки зоны карту, которую можно проверить без движка и отдать в игру с честным масштабом.

## 1.3 Цель продукта

1. Принять бандл съёмки (видео, позы, метаданные, метрическая глубина LiDAR).  
2. Собрать пакет: `map.glb`, `collision.glb`, `manifest.json`, `bounds.json`, `report.json` в размерах датчика.  
3. Дать сборщику пройти по коллизии в браузере и увидеть исходный кадр рядом с мешем.  
4. На плохом входе вернуть отказ с причиной, без подстановки «заглушечной» геометрии.

## 1.4 Видение

> Снял участок ~80×80 см → сервис собрал карту → проверил ходьбой в браузере → забрал GLB в движок и сам выставил масштаб персонажа.

## 1.5 KPI успеха

| ID | Метрика | Порог |
|----|---------|-------|
| KPI-1 | Понимание съёмки | ≥ 4 из 5 людей без 3D-опыта верно называют зону, обход и момент «запись готова» |
| KPI-2 | Проверка без движка | Персонаж ≥ 5 с на поверхности и проходит карту от края до края |
| KPI-3 | Импортируемость | Оба GLB открываются; в манифесте meters и Y-up; пайплайн не rescale’ит под персонажа |
| KPI-4 | Честный отказ | На заведомо плохом входе — fail и непустой текст причины |

### Операционные цели сервиса

| Показатель | Цель |
|------------|------|
| Бандл принят в очередь | ≤ 30 с для эталонного бандла на стабильной сети (без времени сборки) |
| Обновление статуса в UI | Не реже 1 раза в 5 с до финального статуса |
| Повтор с тем же ключом идемпотентности | То же задание, без второй сборки |

## 1.6 Вне цели этого релиза

Полноценная игра; обязательный показ в Unreal; обучение своей модели глубины; Android как основная платформа съёмки; автоматический rescale карты под рост персонажа.
