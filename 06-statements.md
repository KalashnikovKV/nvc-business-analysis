# Заявления

## Использование искусственного интеллекта

Использование инструментов ИИ

| Инструмент | Для чего использован | Как |
|------------|----------------------|-----|
| Claude (Anthropic), Claude Code | Поиск и сравнение аналогов, сбор данных о рынке | Веб-поиск по запросам автора; найденные цифры и описания проверены по ссылкам из списка литературы |
| Claude (Anthropic), Claude Code | Структурирование документа по требованиям к блоку бизнес-анализа | Автор задавал структуру разделов и решения по продукту; модель предлагала формулировки, автор их проверял и правил |
| Claude (Anthropic), Claude Code | Черновики диаграмм, таблиц и критериев приёмки | Модель готовила черновики по требованиям проекта; автор проверял соответствие продукту |
| Claude (Anthropic), Claude Code | Сборка документа | Скрипты, которые собирают сайт, PDF и DOCX из исходных файлов |

Решения о продукте, границах релиза, приоритетах и выборе концепции принимал автор. Все факты из внешних источников сопровождаются ссылками.
