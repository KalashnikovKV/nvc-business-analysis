UML-диаграмма активности с дорожками по ролям. Ручных шагов доводки нет; брак отсекается проверкой записи и отказом сборки.

  subgraph NVC[Система NVC Maps]
    App[Приложение съёмки]

  App <--> ARKit
  App -->|съёмка| API
  Col --> Web
  Web -->|статус, отчёт, карта| API
  API --> Worker
  API <--> Host
  Worker <--> Host
  Dev -->|скачивает пакет| Web
  Dev --> Engine
  Team -->|тестовая ссылка| API

Рис. П.2.4. Диаграмма вариантов использования

%%{init: {"themeVariables": {"fontSize": "20px"}, "sequence": {"messageMargin": 22, "boxMargin": 6, "actorMargin": 40, "messageFontSize": 20, "actorFontSize": 20, "noteFontSize": 18, "mirrorActors": false}}}%%
sequenceDiagram
  actor Op as Оператор съёмки
  participant App as Приложение съёмки
  participant API as Сервис приёма
  participant W as Конвейер сборки
  Op->>App: Записать зону и остановить
  App->>App: Проверить запись
  alt Запись не годится
    App-->>Op: Причина и «Переснять»
  else Запись годится
    Op->>App: Отправить
    App->>API: Съёмка и ключ пользователя
    alt Обрыв связи
      App-->>Op: Ошибка сети, отправку можно повторить
      Op->>App: Отправить ещё раз
      App->>API: Та же съёмка
      API-->>App: Прежнее задание, вторая сборка не стартует
    else Связь есть
      API-->>App: Задание «в очереди»
    end
    API->>W: Задание
    W->>API: Статус «готово» или «отказ» с причиной
  end

Рис. П.2.5. Системная диаграмма последовательности UC-1 «Снять и отправить участок»

%%{init: {"themeVariables": {"fontSize": "20px"}, "sequence": {"messageMargin": 22, "boxMargin": 6, "actorMargin": 40, "messageFontSize": 20, "actorFontSize": 20, "noteFontSize": 18, "mirrorActors": false}}}%%
sequenceDiagram
  actor Col as Сборщик карты
  participant App as Приложение съёмки
  participant Web as Веб-клиент
  participant API as Сервис приёма
  participant S as Хранилище
  Col->>App: Открыть в браузере
  App->>API: Запрос одноразовой ссылки
  API-->>App: Ссылка на 10 минут
  App->>Web: Открыть ссылку
  Web->>API: Обменять ссылку на сессию
  alt Ссылка уже открыта или истекла
    API-->>Web: «Ссылка уже открыта или истекла»
    Web-->>Col: Пустой вход, нужна новая ссылка с телефона
  else Ссылка действует
    API-->>Web: Список заданий пользователя
    Col->>Web: Открыть задание
    alt Сборка завершилась отказом
      API-->>Web: Статус «отказ» и причина
      Web-->>Col: Причина, просмотр и скачивание недоступны
    else Сборка готова
      Web->>S: Опора и кадр съёмки по короткой ссылке
      Col->>Web: Пройти по карте и скачать пакет
    end
  end
