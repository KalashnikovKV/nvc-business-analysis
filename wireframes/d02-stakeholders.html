BA · 02product roles only

Стейкхолдеры, границы, альтернативы

Только роли конечного продукта и границы релиза.

Стейкхолдеры

  • Оператор — зона и preflight
  • Сборщик — загрузка, отчёт, ходьба
  • Разработчик игры — пакет без rescale
  • Владелец сервиса — контейнер, секреты
  • Люди в кадре — без лиц крупным планом

Influence / Interest

Interest → Low High High │ │ Оператор │ │ Сборщик Med │ Владелец сервиса │ Разраб. игры Low │ │ Люди в кадре

Входит

  • LiDAR-съёмка + проверка
  • Пакет в метрах датчика
  • API, очередь, веб-проверка
  • Публичный URL, контейнер

Не входит

  • Rescale под персонажа
  • Полноценная игра / Unreal
  • Своя модель глубины
  • Android как основная съёмка

Альтернативы

  • Meshroom/RealityScan — нет единого пакета и быстрой проверки
  • Только монокуляр — нет надёжных размеров в метрах; резерв
  • Polycam/KIRI — чужой закрытый контракт
  • RoomPlan — комната, не patch ~80×80 см

Выбор: LiDAR → свой пайплайн → GLB → ходьба в браузере.
