Резюме, проблема, цели

Короткая LiDAR-съёмка зоны → пакет игровой карты → проверка ходьбой в браузере → GLB в движок.

Сейчас

  • Есть только видео
  • Ручная фотограмметрия + правка
  • Проверка только в движке
  • Нет единого контракта пакета

Нужно

  • Визуал + коллизия в метрах датчика
  • Один воспроизводимый прогон
  • Проверка в браузере до импорта
  • Метрики и явный отказ

Цель продукта

  • Принять бандл (видео, позы, meta, глубина)
  • Собрать 5 файлов пакета
  • Ходьба + исходный кадр в браузере
  • Fail с причиной, без заглушки

KPI

  • KPI-1 понимание съёмки ≥ 4/5
  • KPI-2 ходьба ≥ 5 с, край–край
  • KPI-3 meters / Y-up, без rescale
  • KPI-4 честный fail на плохом входе
