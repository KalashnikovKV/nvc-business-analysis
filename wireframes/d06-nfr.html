BA · 06readiness

NFR, риски, готовность

NFR

  • NFR-1 воспроизводимость ±15%
  • NFR-2 код на английском
  • NFR-3 секреты вне git/образа
  • NFR-4 проверка без движка
  • NFR-5 конфиг воспроизводим
  • NFR-6 публичный URL + контейнер

Риски

  • Неузнаваемый меш → малая зона, позы, fail
  • Нет LiDAR у проверяющего → эталонные бандлы
  • Тяжёлая зона → 80×80 default
  • Случайный rescale → запрет в манифесте
  • Обрыв upload → idempotency + retry

Этика данных

  • Пол / стол / макет
  • Без лиц крупным планом
  • Доступ по API-ключу на старте

Готовность релиза

  • Понятный preflight
  • Отчёт + ходьба в браузере
  • Пакет meters / Y-up
  • Честный отказ
  • KPI-1…4 и NFR-1…6
