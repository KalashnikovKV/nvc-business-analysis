# Бизнес-анализ NVC Maps

Блок бизнес-анализа по требованиям 2026/27: введение, глава 1, глава 2, литература, приложения 1 и B, заявления. Требования к блоку — `../diplom-docs-2026-09-27/1_Business Analysis Block Requirements…pdf`. Правила — `BA-METHOD.md`, оглавление — `README.md`.

## Структура

- `00`–`06-*.md` — исходные разделы. Пока на русском; итоговый DOCX эксперту нужен на английском.
- `04-appendix-a-backlog.md` и `NVC-Maps-бизнес-анализ.md` генерируются — правки только в разделах.
- `scripts/slides.py` — презентация для защиты: описание слайдов данными; из него собираются `wireframes/deck.html` и PowerPoint `wireframes/NVC-Maps-защита.pptx` (`scripts/build-pptx.mjs`). Состав: 8 слайдов, запасные слайды и ответы на вопросы комиссии. Правила: одна мысль, до 30 слов, ссылка на раздел внизу, линия «проблема → цель → показатель → эпик», без сокращений и идентификаторов (никаких KPI, NFR, US-4.1, «мин», «ст.»). Цифры — из разделов 00–02, при их правке обновлять и слайды.
- `wireframes/` — сайт (GitHub Pages): `d0X-*.html` генерируются из разделов, `m*`/`b*` — макеты экранов, `shots/` — скриншоты макетов, `BA_Kalashnikov_Kirill.docx` и PDF — для скачивания.

## Команды

```bash
python3 scripts/build-ba.py          # бэклог, сводный файл, сайт, DOCX и PDF
python3 scripts/build-ba.py shots    # скриншоты макетов после правки m*/b*
npx markdownlint "**/*.md" --ignore node_modules --config .markdownlint.json   # как в CI
```

## Правила

- Пишем про продукт, а не про диплом: научный руководитель и комиссия — не стейкхолдеры.
- Админки в релизе нет — решение владельца продукта, не добавлять.
- Истории в 2.5 — строки таблиц `| US-x.y | … | … | Must |` под заголовками `### Ex.`; генератор бэклога читает именно этот формат.
- Источники — в `references.json` (bib, полная и краткая сноска). В тексте ссылка `[@ключ]` или `[@a; @b]`; `03-references.md` генерируется, вручную не править.
- Новые обязательные файлы добавлять в список проверки в `.github/workflows/ci.yml`.
- Оформление DOCX — по «Правилам оформления письменных работ ЕГУ» (`../diplom-docs-2026-09-27/Rules for students papers_2025_final_RUS.pdf`): TNR 12, интервал 1,5, поля 25/10/20/20 мм, текст по ширине, заголовки разделов прописными по центру, номер страницы справа вверху. Ссылки — постраничные сноски по Чикагскому стилю, главы — «1. АНАЛИТИЧЕСКАЯ ЧАСТЬ» без слова «Глава». Приложения нумеруются цифрами («ПРИЛОЖЕНИЕ 1» в правом верхнем углу), рисунки и таблицы в них — «Рис. П.2.1», «Табл. П.1.1».
- Каждой таблице в разделах — подпись `Табл. N.M. Название` строкой перед таблицей и ссылка «(табл. N.M)» в тексте; рисункам — подпись «Рис.» под рисунком.
- После сборки смотреть `.build/docx-preview.pdf` глазами.
- Не читать `node_modules/`, `.build/` и PDF/DOCX без необходимости.
