## Use of Artificial Intelligence

Use of AI tools

| Tool | What it was used for | How |
|------|----------------------|-----|
| Claude (Anthropic), Claude Code | Searching for and comparing analogs, collecting market data | Web search on the author's queries; figures and descriptions found were checked against the links in the list of references |
| Claude (Anthropic), Claude Code | Structuring the document according to the business-analysis block requirements | The author set the section structure and product decisions; the model proposed wording, which the author checked and edited |
| Claude (Anthropic), Claude Code | Drafts of diagrams, tables and acceptance criteria | The model prepared drafts from the project requirements; the author checked them against the product |
| Claude (Anthropic), Claude Code | Translation into English | The model translated the author's Russian text; the author checked the translation |
| Claude (Anthropic), Claude Code | Document assembly | Scripts that build the website, PDF and DOCX from the source files |

Decisions about the product, release scope, priorities and the choice of concept were made by the author. All facts from external sources are referenced.
