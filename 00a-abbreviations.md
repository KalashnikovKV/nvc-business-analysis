# Список сокращений

| Сокращение | Расшифровка на языке оригинала | Значение |
|------------|--------------------------------|----------|
| API | Application Programming Interface | Программный интерфейс приложения |
| AR | Augmented Reality | Дополненная реальность |
| AS-IS, TO-BE | — | Текущий и целевой процесс |
| BABOK | Business Analysis Body of Knowledge | Свод знаний по бизнес-анализу |
| BG | Business Goal | Бизнес-цель (BG-1–BG-4) |
| E | Epic | Эпик (E1–E6) |
| GDPR | General Data Protection Regulation | Общий регламент ЕС о защите персональных данных |
| GLB, glTF | GL Transmission Format (binary) | Открытый формат 3D-моделей и его двоичный вариант |
| ID | Identifier | Идентификатор |
| KPI | Key Performance Indicator | Ключевой показатель эффективности |
| LiDAR | Light Detection and Ranging | Лазерный датчик глубины |
| MoSCoW | Must, Should, Could, Won't | Метод приоритизации требований |
| NFR | Non-Functional Requirement | Нефункциональное требование |
| R | Risk | Риск (R1–R7) |
| S, N | — | Эталонные съёмки: пригодные S1, S2 и непригодные N1, N2 |
| UC | Use Case | Сценарий использования |
| UML | Unified Modeling Language | Унифицированный язык моделирования |
| US | User Story | Пользовательская история |
| WCAG | Web Content Accessibility Guidelines | Руководство по доступности веб-контента |
